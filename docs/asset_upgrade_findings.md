# نتائج ترقية النماذج والخامات

تم استبدال أجزاء النماذج الإجرائية بمكونات عسكرية منخفضة التفاصيل: سترات وخوذ وحقائب وأرجل وبنادق للمشاة، جسم مموه وبندقية بمنظار وقواعد ارتكاز للقناص، كبائن وزجاج للمركبات، سطح تتبع وبرج وسبطانة وهوائي للدبابات.

تم إنشاء خامات إجرائية أصلية قابلة للتكرار مع خرائط `albedo` و`normal` و`roughness` للعشب والتراب والصخور والطريق، إضافة إلى خامة ماء بخرائط موجية، وربطها بمواد Terrain في Godot.

نجح تشغيل اللعبة والتقاط اللقطات دون أخطاء GDScript أو Parse Error. ظهرت تفاصيل الوحدات بصورة أوضح، لكن المعاينة ما زالت تُظهر أن الأرضية الفعلية لا تُظهر نسيجًا قويًا في اللقطات الحالية؛ السبب المحتمل هو تفاعل `vertex_color_use_as_albedo` مع الخامة أو إعداد UV في شبكة الأرض، ويجب تحسين ذلك في مرحلة لاحقة بإزالة اعتماد اللون الرأسي أو فصل مواد الارتفاعات إلى مناطق مستقلة.
